01

MoonBit owns the behavior.

Typed state, bounded edits, min/max validation, flex resolution and coordinate comparison compile to JavaScript. HTML controls and Canvas 2D are the browser host.

02

Historical evidence stays historical.

The saved result index is an excerpt of published measurements. Raw execution artifacts were not revalidated here. A live match compares coordinates to that record; it is not a new upstream run.

03

A deliberately small slice.

One definite flex line, two children. No wrapping, intrinsic text sizing or full CSS parity. Device-pixel snapping can differ. This experimental JS/Canvas host does not establish native rendering, input or IME parity.
